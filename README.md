# Our Vibe — QR Website Prototype

## Included

- Mobile-first camera landing page
- Automatic song selection from a song pool
- Multi-vibe song tags
- Smart shuffle with same-day no-repeat
- Longer history so yesterday's song does not automatically repeat
- Editable song/photo admin page
- YouTube links
- Photos section

## Important

This is the first editable prototype.

The current admin uses browser localStorage,
so it is NOT yet a shared public database.

Changes made on one device/browser will not
automatically appear on another device.

For the final QR deployment, the next step is
to connect the admin to a hosted database/storage
service and protect `/admin` with authentication.

The camera experience intentionally does NOT infer
emotions from facial images; the vibe engine is a
non-biometric selection system.
